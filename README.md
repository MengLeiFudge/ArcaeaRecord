# arcaeaRecord

由 萌泪、梦想天生、yyq2517 编写的Arcaea脚本生成程序

## 如何运行

<ul>
    <li>修改 {@link #ARC_DIR} 至合适的目录</li>
    <li>将最新的 arcaea 安装包（如 arcaea_4.1.0c.apk）放至 {@link #ARC_DIR} 内</li>
    <li>用雷电模拟器下载全部的歌曲，并将 dl 文件夹移动至 Pictures 内</li>
    <li>打开雷电模拟器脚本路径，将其复制到 {@link #VMS_DIR}</li>
    <li>运行程序！enjoy it！</li>
</ul>
